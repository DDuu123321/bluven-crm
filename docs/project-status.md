## 1. 现在在哪一步

**开发已经完成，还没有上线。**

从线索进入到尾款到账、关闭工单，整条流程都已做好，并有自动化测试覆盖。接下来是部署、接通真实服务、和员工一起验收。

## 2. 已完成的部分

| 部分 | 内容 |
|---|---|
| 线索 | 从网站后台自动取线索、接收接口、CSV 导入、手动录入；按电话和邮箱去重；主管分派；闲置提醒和退回线索池 |
| 销售 | 开工并选线索来源；电话、备注、待办和时间线；资料夹和推送清单；报价版本和签字版；定金和凭证；推送运营 |
| 运营 | 接收订单并确认定金；工单六项；补传资料和备注；通知客户日期；完工；补贴和尾款提醒；请销售催尾款；确认尾款并关闭工单；特殊情况退回销售 |
| 财务 | Payments 页：定金、待收尾款、已收尾款、待退款；到账时收到通知 |
| 客户邮件 | 每位销售连接自己的 Zoho 邮箱，在 CRM 里收发邮件，附件存进订单资料；三封自动发给客户的邮件及其模板 |
| Pylon | 关联 Pylon 项目，读取设计、报价和签字文件，处理 Pylon 发来的事件 |
| AI 助手 | 订单总结、信息抽取、附件识别、账单读取、回信草稿、交接简报；每天、每张订单和每人都有用量上限 |
| 管理 | 用户和角色、各项设置、站内通知和每日摘要邮件、仪表盘和订单导出、资料保留、操作日志 |
| 部署 | Docker 镜像、Docker Compose（含 HTTPS 和备份脚本）、Railway 的部署步骤 |

## 3. 质量情况

- **自动化测试**：443 个单元和集成测试，直接连数据库运行；32 个浏览器测试，从线索一直走到关闭工单。2026-11-18 在当前代码上全部通过。
- **代码审查**：做过三轮，分别针对安全、业务规则，以及邮件、AI 和资料保留。发现的问题已逐条处理。
- **数据量**：按 2 万张订单、10 万份资料测过主要查询，最慢的全局搜索约 0.4 秒。
- **演示**：在演示数据上以每个角色把页面走过一遍。

上线前建议请另一位开发者重点看一遍权限、金额和外部接口相关的代码。

## 6. 待负责人确认

本期按下面的理解实现，负责人没有明确说过，可以改：

1. 客户明确拒绝的订单关闭但不删除，按丢单处理，订单和资料留档。
2. 通知客户安装日期和到货的邮件由运营点按钮发出，不是填完日期自动发。
3. 方案发出后单独显示为"方案已发"阶段，含义仍是继续跟进。
4. 闲置天数默认 5 / 8 / 10 天：提醒销售、提醒主管、退回线索池。
5. 财务软件（Xero）暂不对接，只在站内和邮件通知财务。

已给出初始值、可在后台修改的设置：线索来源七项、丢单原因十项、推送必备资料三类（电费账单、安装位置照片、电表箱照片）、定金建议比例 10%、补贴提醒 2 个工作日、尾款提醒 5 个工作日、三封客户邮件的英文模板。三封邮件的措辞请负责人过目。

还没定的：

- 网站接口要不要补上月电费、购买时间、备注等询价信息，由网站一侧决定，写法见对接说明 A.4。
- 完工后申请补贴所需的安装方证件，会上提到，暂不处理。
